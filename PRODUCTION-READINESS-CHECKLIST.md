## Validation boundaries

- The production server was exercised with placeholder Supabase values. Compilation, responsive rendering, headers and browser behavior are verified; live Supabase authentication, RLS, uploads, messaging, CMS writes and Resend delivery are **not** certified by that run.
- Browser property records and ambiguous/no-match geocoder responses are intercepted QA fixtures only. They are not production inventory and are never written to Supabase. The single-result `Ikeja, Lagos` check used the real Nominatim integration.
- The consolidated SQL migration has not yet been applied to a staging or production database. Its first-admin procedure is documented in `RENDER_DEPLOYMENT.md` and still requires execution against the intended auth user.

## Fixes included in the Render migration

- Removed `vercel.json`, `.vercelignore`, and the old Vercel deployment guide.
- Moved hosting-specific headers into portable Next.js configuration.
- Corrected wildcard CORS so it is not combined with credentialed requests.
- Added a dependency-free Render health check.
- Upgraded Next.js from a vulnerable release to pinned `16.4.5` and resolved audit findings.
- Fixed the admin moderation TypeScript build blocker.
- Fixed password recovery to use the existing `/auth/reset-password` page and removed the redirect that made it unreachable.
- Fixed production email sending to honor `EMAIL_FROM` and `EMAIL_REPLY_TO`.
- Replaced provider-specific site URL fallbacks with `NEXT_PUBLIC_SITE_URL` and Render's `RENDER_EXTERNAL_URL`.
- Removed committed admin credentials from current documentation and added rotation instructions.
- Corrected README/Quick Start schema references to `supabase-schema.sql`.

## Production-core and frontend work included

- Added all-content administration for properties, developments, agencies, agents, insights/articles, reviews, global settings, enquiries, inspections and individual email history, using cookie-authenticated RLS-scoped APIs.
- Removed demo public-inventory fallbacks and misleading stock-image fallbacks; unmapped properties are labelled as awaiting a saved location instead of receiving invented coordinates.
- Reworked the responsive shell, homepage search, property grid/list/split-map views, roomier listing descriptions, property details, global footer and mobile navigation.
- Standardised Nigerian price/period formatting and neutral missing-property images across cards and related-property views.
- Added accurate Leaflet/OpenStreetMap markers, saved-location counts, address-result details, directions, closer single-result zoom and explicit selection for ambiguous geocoder matches.
- Hid experimental store/AI/blockchain/academy journeys from the production navigation rather than presenting simulated outcomes.
- Disabled development service-worker registration and updated worker cache v2.2 to bypass APIs, cross-origin requests and private account/admin navigations.
- Removed public AdSense setup placeholders; unconfigured ad units render nothing.
